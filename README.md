# Hospital Management System

A web-based hospital management application built with React, Vite, Node.js, Express, and MongoDB/Mongoose. The application is intended to help healthcare teams organize doctor information and appointment-related workflows.

## Intended users
- Clinics and healthcare teams evaluating a customizable management application
- Developers who want to extend the application for a specific organization

## Main technology
- Frontend: React, Vite, Tailwind CSS, React Router, Axios
- Backend: Node.js, Express
- Database: MongoDB Atlas with Mongoose
- Authentication libraries: JWT and bcrypt
- Optional integrations present in dependencies: Cloudinary/Multer for media handling and Razorpay for payments

## Features
The repository's supplied package manifests confirm the technology stack, but they do not confirm every application feature. Review the running application and source code before advertising features such as patient records, admin roles, payment processing, or specific security controls.

## Local development
1. Configure the backend environment variables using `.env.example` as a checklist.
2. Install and start the backend from `backend/`.
3. Install and start the frontend from `frontend/`.
4. Configure the frontend API base URL to match the backend.
5. Follow `HowToSetup.md` for details.
